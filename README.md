# The GenWin Dashboard

A GenAI-powered financial workbook generator prototype built for a hackathon.

This project delivers a high-fidelity, interactive, and demo-ready prototype of an AI dashboard that handles automated financial analysis. It leverages a clean, stable UI architecture designed strictly with Tailwind CSS flexbox utilities.

## Tech Stack
- **Framework**: React 19 + TypeScript
- **Tooling**: Vite
- **Styling**: Tailwind CSS v3

## Setup Instructions

Ensure you have Node.js installed, then follow these steps:

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Run the development server**
   ```bash
   npm run dev
   ```

3. **Open in browser**  
   Navigate to [http://localhost:5173](http://localhost:5173) in your browser.
